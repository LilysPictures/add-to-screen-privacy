Privacy Policy

Add to Screen / «Добавь на экран» (LilysPictures)
Last updated: 9 November 2026

English

Add to Screen is a browser extension that lets users place animated stickers on webpages and optionally use a custom mouse cursor.

What we store

The extension stores only local preferences in the browser using chrome.storage.local: selected stickers, sticker positions/counts, and the selected cursor.

What we do not collect

  • No personal identity data
  • No browsing history collection
  • No analytics or advertising trackers
  • No transmission of page contents to external servers

Network access

The extension works offline with packaged assets. It does not send user data to our servers because we do not operate a backend for this extension.

Permissions

Broad site access is used only to display stickers/cursors on pages the user visits. storage saves preferences locally. scripting injects the content script into already open tabs after install or update.

Русский

«Добавь на экран» — браузерное расширение, которое позволяет размещать анимированные стикеры на веб-страницах и при желании менять курсор мыши.

Что сохраняется

Только локальные настройки в браузере через chrome.storage.local: выбранные стикеры, их позиции/количество и выбранный курсор.

Что мы не собираем

  • Персональные данные пользователя
  • Историю посещений
  • Аналитику и рекламные трекеры
  • Содержимое страниц для отправки на внешние серверы

Сеть

Расширение использует встроенные файлы и не отправляет данные пользователя на наши серверы, потому что отдельного серверного бэкенда у расширения нет.

Разрешения

Доступ к сайтам нужен только чтобы показывать стикеры и курсор на страницах. storage хранит настройки локально. scripting подключает скрипт к уже открытым вкладкам после установки или обновления.
